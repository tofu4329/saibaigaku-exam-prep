# (G5560) 栽培学 試験対策ポータル

第1回（10/23）〜第5回（11/20）の講義資料・図版、および NotebookLM 試験対策ノートの要点を統合した静的 Web 学習アプリです。

## 主な機能
- **単元別ノート（全5回）**：SVG図解・比較表・施肥量算出シミュレータ付き
- **🟥 赤シートモード**：重要語句を赤く隠し、個別クリックでめくって暗記確認
- **🃏 一問一答フラッシュカード**：29問・単元フィルタ・未習得のみ抽出・シャッフル対応
- **📝 4択実戦テスト**：15問・ランダム10問・間違えた問題だけの自動復習モード
- **✍️ 記述・論述式 試験対策**：17問・必須キーワード表示・模範解答・習得チェック
- **🔍 横断検索 ＆ 🌙 ダークモード**：キーワード即時検索、`localStorage` による進捗自動保存

## GitHub Pages 公開
`.github/workflows/pages.yml` および `.nojekyll` を同梱しています。
リポジトリ設定の **Settings > Pages > Source** で **GitHub Actions**（または `Deploy from a branch` の `main`）を選択すると公開されます。
